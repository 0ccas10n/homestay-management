# NOTES.md Format

`NOTES.md` is a working scratchpad. It captures the **meta** — how the learner learns best, what they like and don't like, and any session-specific context that future sessions will need.

This is distinct from `MISSION.md` (the *why*) and `learning-records/` (the *what was learned*). Notes are about *how*.

## Template

```markdown
# Teaching Notes

## Learner profile

- **Time per session**: [Approx. minutes]
- **Sessions per week**: [Number]
- **Preferred pace**: [Slow & deep | Balanced | Fast & wide]
- **Best modality**: [Reading | Video | Hands-on | Mixed]
- **Background**: [Brief relevant background — work, education, prior projects]

## Preferences

Things the learner has explicitly asked for or reacted positively to:
- E.g. "Likes seeing real-world examples before theory"
- E.g. "Wants short exercises, not 30-minute drills"
- E.g. "Prefers being quizzed at the end of each section"

## Anti-preferences

Things the learner has said they don't like or react badly to. Respect these in every lesson:
- E.g. "Hates animations in teaching material"
- E.g. "Loses patience with theory before practice"
- E.g. "Doesn't want analogies — wants the raw thing"

## Working notes

Free-form scratchpad for the current session or recent context. Update frequently.

[Date]: [Note]
[Date]: [Note]
```

## Update Cadence

- Update **preferences** only when the learner has stated them clearly
- Update **working notes** at the start and end of every session
- Prune **working notes** when they become stale (move durable insights to a learning record)
