# RESOURCES.md Format

A curated list of high-quality, high-trust resources for the topic. Every lesson should cite at least one resource from this list. Never trust parametric knowledge alone — always ground claims in these resources.

## When to Write

Populate `RESOURCES.md` early in the journey (first or second session). Add to it whenever a new high-quality source is discovered.

## Template

```markdown
# Resources: [Topic]

**Last curated**: [YYYY-MM-DD]

## Primary (use these as lesson foundations)

These are the most authoritative, well-written, and accurate sources. Lessons should cite from here first.

### [Resource title]
- **Type**: [Book | Video | Course | Article | Docs | Paper]
- **Author / Source**: [Author name or organization]
- **URL**: [Link]
- **Why it's good**: [1–2 sentences on the source's strengths and credibility]
- **What it's good for**: [Specific topics or skills this is best at teaching]

### [Resource title]
...

## Secondary (use for deep dives and exercises)

Resources useful when the learner wants to go deeper on a specific subtopic or wants practice problems.

### [Resource title]
...

## Community (for wisdom, not facts)

Forums, subreddits, Discord servers, meetups, or courses where the learner can test their skills against real practitioners. Add here when the user starts needing judgment-based answers.

### [Community name]
- **Platform**: [Subreddit | Discord | Meetup | Forum]
- **URL**: [Link]
- **Activity level**: [High / Medium / Low]
- **Best for**: [What kinds of questions to bring here]

## Anti-recommendations

Resources the learner should avoid. Examples: outdated tutorials, content farms, sources with persistent factual errors. Include the reason so future sessions don't accidentally cite them.

- [Resource title] — [Reason to avoid]
```

## Curation Principles

- **Quality over quantity**. 5 excellent resources beat 50 mediocre ones.
- **Cite sources that load fast and look modern** — the learner will return to these.
- **Mix modalities**. Some learners absorb better from video, others from text.
- **Update the date** at the top whenever a resource is added or removed.
